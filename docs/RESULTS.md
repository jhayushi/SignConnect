## Noisy streams and thresholds

Each fixture is replayed for 48 frames at 30 fps. Frames stay on the recorded pose except every 22nd frame, which adds Gaussian noise with sigma 0.015 (seeded, so the run is repeatable). That is a brief loss of the pose about every 0.73 s. The sentence builder then tries to commit one word. A trial is correct when the committed words are exactly the fixture label, or empty when the fixture is a pose reserved for a MediaPipe gesture.

The previous defaults were minConfidence 0.7, holdMs 1000, releaseMs 400. The sweep keeps releaseMs at 400. It picks the row with the most correct trials, then the fewest false commits, then the shorter hold.
